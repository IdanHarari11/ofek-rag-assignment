# מילון מונחים – Glossary

| עברית | English | הסבר |
| --- | --- | --- |
| השתתפות עצמית | Deductible / Excess | הסכום שהמבוטח נושא בו בכל מקרה ביטוח |
| סכום ביטוח | Sum Insured | הסכום המרבי שהמבטח ישלם |
| פרמיה / דמי ביטוח | Premium | הסכום שהלקוח משלם עבור הביטוח |
| נספח / הרחבה | Rider / Endorsement | תוספת לפוליסה שמרחיבה או משנה כיסוי |
| כתב שירות | Service Note | שירות נלווה (גרירה, שמשות) שניתן על ידי ספק |
| חתמות | Underwriting | הערכת הסיכון והחלטה אם לבטח ובאיזה מחיר |
| תחלוף | Subrogation | זכות המבטח לתבוע צד שלישי אחרי ששילם |
| אובדן גמור | Total Loss | נזק שעלות תיקונו מעל 60% משווי הרכב |
| שמאי | Loss Adjuster / Appraiser | מעריך הנזק מטעם החברה |
| ערך כינון | Replacement Value | פיצוי לפי מחיר פריט חדש |
